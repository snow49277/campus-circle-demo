# 校园互助平台 · 产品 Demo 项目

我希望让人们用自己能提供的帮助，获得自己需要的帮助。我将大学校园作为首轮验证场景，长期面向有技能与经验交换需求的大众。

**当前进展：我已完成互助网页 Demo、竞品分析、PRD 和流程文档，并加入需求对话、可编辑需求卡与辅助匹配流程。我已完成 DeepSeek 服务端接口，真实模型联调将在开通 API 并配置密钥后进行；目前公开展示的是已标注的预设交互示例。**

## 我的产品原则

我将“一次帮助换一次帮助”作为核心规则，并围绕以下原则设计产品：

- 一次双方认可的帮助，换一次获得帮助的机会；不按技能、时长或难度定价。
- 支持直接互换、多人互助环，以及跨时间保留尚未获得回报的贡献。
- 允许先获得一次帮助；尚未完成对应付出时，暂不能再次接受帮助。
- 同校身份、经历作品、互助反馈和可选沟通帮助用户判断是否适合。
- 已完成贡献不因环断裂而消失；持续关系由双方自愿继续。

## 本地运行

我在 V0.2 中使用 Vinext 和 Cloudflare Worker 提供服务端 AI 接口，本地运行环境为 Node.js 22.13 或更新版本。

```sh
cd site
npm ci
npm run dev
```

本地启动后，终端会显示访问地址（默认 `http://127.0.0.1:5173`）。我通过 `npm test` 验证29项业务与接口测试，测试使用模拟模型响应。

我在 AI 文档中记录了真实模型的接入方式、变量名和费用控制边界，密钥仅通过服务端秘密配置管理。

## 我的演示路径

我用以下路径展示从表达需求到完成互助的完整流程：

1. 进入“AI 需求助手”，选择预设想法，补齐条件并确认需求卡；或直接发布供需。
2. 进入“我的互助环”，发起三人环。
3. 用底部控制台切换林予、周禾、陈一，分别确认邀请。
4. 在“我的约定”中，帮助者提交完成，接受者确认。
5. 尝试底部的成员退出、持续互助和先接受后付出场景。
