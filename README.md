# 校园互助平台 · 产品 Demo 项目

让同一所大学的学生用自己能提供的帮助，获得自己需要的帮助。

**当前阶段：已实现可操作的网页 Demo，并完成竞品研究、PRD 和流程文档初稿。产品名称暂用“校园互助”。**

## 产品原则

- 一次双方认可的帮助，换一次获得帮助的机会；不按技能、时长或难度定价。
- 支持直接互换、多人互助环，以及跨时间保留尚未获得回报的贡献。
- 允许先获得一次帮助；尚未完成对应付出时，暂不能再次接受帮助。
- 同校身份、经历作品、互助反馈和可选沟通帮助用户判断是否适合。
- 已完成贡献不因环断裂而消失；持续关系由双方自愿继续。

## 本地运行

需要 Node.js 22 或更新版本，无需安装第三方依赖。

```sh
cd site
npm start
```

在浏览器中打开终端显示的本地地址（默认 `http://127.0.0.1:4173`）。执行 `npm test` 运行规则测试。

## 体验顺序

1. 进入“我的互助环”，发起三人环。
2. 用底部控制台切换林予、周禾、陈一，分别确认邀请。
3. 在“我的约定”中，帮助者提交完成，接受者确认。
4. 尝试底部的成员退出、持续互助和先接受后付出场景。

## 实现边界

这是虚构校园的单浏览器演示。没有真实认证、实时消息、生产级匹配与远程数据存储；不收集真实学生信息。各功能的实现情况和未完成项见验证文档。PRD 描述的完整目标产品大于当前 Demo 范围。

在线网页已公开发布；源码与文档保存在本仓库。
