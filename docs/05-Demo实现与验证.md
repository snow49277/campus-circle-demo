# Demo 实现与验证

日期：2026-10-17｜版本：v0.1

## 已实现

- 构建无需第三方运行依赖的 HTML/CSS/JavaScript 页面，使用本地存储保留演示数据。
- 校园广场、分类与关键词筛选、供需发布、本人条目编辑和暂停、名片与示例作品。
- 基于实际数据搜索两人互换及三人环；部分确认、全员确认、失效、拒绝、模拟超时。
- 独立约定、预约资格占用、完成确认、重复操作保护、取消与争议演示。
- 多人环退出后保留贡献，单向自愿替补；完成后邀请下一期并重新检查资格。
- 本地对话与反馈；五个独立演示场景，切换身份操作。
- 项目内置 PRD、竞品分析和流程文档入口。

## 验证结果

自动测试命令：在 `site` 中执行 `npm test`。12 项规则测试覆盖匹配、部分确认、失效、资格限制、确认权限、重复完成、退出保留、替补、取消、续约、反馈、编辑失效与超时。测试结果以实际终端执行为准。

已在 Codex 内置浏览器实际操作：

1. 找到三人候选、发起邀请，并切换三名成员分别确认。
2. 按 A→B、B→C、C→A 顺序完成三条帮助；确认每人最终提供和接受各一次。
3. A→B 完成后，B 的页面显示需先付出的限制；B 实际帮助 C 后限制解除。
4. 载入退出场景，确认已完成贡献保留，邀请 D 为 A 提供单向替补，不要求 A 再付出。
5. 检查窄屏布局，并修正中等宽度下的标题拥挤问题。

## 明确的实现边界

- 这是单浏览器交互 Demo，不是真实多用户服务。切换身份、双方同意勾选与争议处理都明确标注为模拟。
- 目前匹配采用预定义技能与两个可用时间段，尚未实现任意时间日历、复杂时段冲突处理或大规模最优匹配。候选环内顺序安排不同时间；单向与续约时间由双方另行沟通，页面明示。
- 退出修复展示单向替补，不声称可以自动重建任意规模的完整闭环。
- 编辑的是发布条目；已建立约定保留原范围。复杂的已确认约定版本协商尚未实现。
- 邀请超时可手动模拟；尚无真实后台计时、推送或接受者超时提醒任务。
- 暂无真实校园认证、文件上传、举报审核后台、拉黑、远程权限和多设备事务。PRD 中这些属于目标产品要求，不能作为当前 Demo 已通过的验收项。
- 页面有响应式布局，已在当前内置浏览器窄屏检查；尚未完成各手机型号、桌面宽度和屏幕阅读器的全量验证。
- 中文字体可从 Google Fonts 加载，失败时使用系统字体；无需外部图片素材。

## 演示方法

第一次建议保持“林予 / 从零开始”，进入“我的互助环”发起邀请，再用底部身份选择器切换三人确认。进入“我的约定”，提供者提交完成，接受者确认。

底部场景选择器可载入“先接受后付出”“成员退出与替补”“持续互助”“暂无匹配”。载入会重置当前浏览器的示例状态，操作前有确认提示。演示输入不要包含真实私人信息。
